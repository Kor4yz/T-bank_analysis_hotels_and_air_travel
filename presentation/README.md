# Презентация проекта «T-Bank: Hotels & Air Travel»

В этой папке находятся материалы презентации, отражающие ключевые выводы, визуализации и рекомендации по анализу бронирований отелей и авиаперелётов.

---

## Содержимое

- `T-Bank.pptx` — презентационный файл PowerPoint (или другой формат: PDF, Keynote).  
- `T-Bank.pdf` — экспорт презентации в PDF (для публикации/рассылки).  
- `README.md` — этот файл-описание.

---

## Что включено в презентацию

1. **Обзор проекта**  
   — цель, задачи, источники данных.  
2. **Методология**  
   — как подготовлены данные, что чистили, аггрегировали, какие метрики использовались.  
3. **Ключевые выводы**  
   — тренды бронирований, основные направления авиаперелётов и отелей, поведение клиентов, сегментация.  
4. **Рекомендации**  
   — на основе анализа: как можно улучшить бизнес-процесс, увеличить оборот, повысить удержание клиентов.  
5. **Приложения / дополнительная информация**  
   — примеры таблиц/графиков, прогнозы, следующий шаг.
