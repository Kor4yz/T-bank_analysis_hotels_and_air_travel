# Ноутбуки проекта «T-Bank: Hotels & Air Travel»

В этой папке находятся Jupyter-ноутбук, используемые для исследования, визуализации и подготовки данных по анализу бронирований отелей и авиаперелётов.  
Они служат для интерактивного исследования, иллюстрации гипотез, генерации графиков и дальнейшего построения дашбордов/моделей.
